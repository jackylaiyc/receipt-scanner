# PWA Icons

You need to provide the following PNG icon files in this directory:

- `icon-192.png` (192x192px) — Used by Android and PWA manifest
- `icon-512.png` (512x512px) — Used by PWA install screens
- `apple-touch-icon.png` (180x180px) — Used by iOS "Add to Home Screen"

## How to generate icons:

1. Create a 512x512 image of your receipt scanner logo
2. Use a tool like https://realfavicongenerator.net to generate all sizes
3. Or use any image editor to resize to the required dimensions

## Temporary placeholder:
Until you add real icons, the app will still work — iOS will use a screenshot as the home screen icon.
